# symploke-sonora

Laboratorio de ontología materialista de la música mediante software libre.

## Qué es esto

No es un portafolio. No es un currículum. Es un argumento filosófico
en forma de código y sonido. Aquí se explora la música como realidad
ontológica a través de tres géneros de materialidad (M₁, M₂, M₃) y su
entrelazamiento (*symploké*), usando exclusivamente herramientas libres.

## Cómo usar este repositorio

1. Lea el ensayo en `ensayo/symploke-sonora.org`
2. Explore el código en `codigo/`
3. Escuche las piezas en `portafolio/`
4. Lea las fichas ontológicas de cada pieza
5. Si encuentra algo útil, úselo. El conocimiento es libre.

## Principios

- **Acceso libre y total:** El código y el conocimiento no deben tener barreras.
- **Desconfiar de la autoridad:** Ni corporaciones ni gobiernos son dueños del saber.
- **Juzgar por el mérito:** Solo la calidad del trabajo importa.
- **La información debe ser libre:** Pero quien la libera necesita protección.
- **Somos cyberpunks.** Que nadie lo sepa.
